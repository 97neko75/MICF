# MICF – 才…才不是给你用的内核呢！

一个能读写 FAT32、会卖萌的操作系统内核。 

虽然名字叫 Microkernel formal FobOS，但其实已经是宏内核了啦～别问为什么，问就是杂鱼。

## 这玩意儿能干啥？

- 开机给你一个 `>` 提示符，你可以输入命令（像 DOS 一样老土）。
- 读文件、写文件、删文件、建目录、删空目录……基本文件操作都齐了。（有bug不想修~ ~作者可真是杂鱼呢~）
- 磁盘格式只认 **FAT32**，别拿 NTFS 来烦我。
- 跑在 QEMU 里，真机？你自己试，炸了别哭。

### 命令列表（记不住是你笨）

| 命令 | 作用 |
|------|------|
| `help` | 瞅瞅我有多厉害 |
| `echo <text>` | 你说什么我就复读什么 |
| `clear` | 屏幕脏了擦一擦 |
| `reboot` | 重启（虚拟机限定） |
| `ls` | 看看盘里有什么垃圾 |
| `cat <file>` | 偷看文件内容 |
| `write <file> <text>` | 写点东西进去 |
| `mkdir <dir>` | 建个文件夹 |
| `del <file>` | 删文件 |
| `rmdir <dir>` | 删空文件夹（非空？杂鱼～） |
| `fatinfo` | 显摆一下FAT32参数 |

## 怎么编译？

你该不会连 i686-elf-gcc 都没有吧？  

有的话，双击 `build.bat` 

就能生成  `micf.elf`。

然后执行：
```bash
qemu-system-i386 -kernel micf.elf
```
